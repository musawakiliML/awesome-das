> A curated collection of resources for **Distributed Acoustic Sensing (DAS)**.

Awesome DAS is an open-source, community-curated collection of resources for learning, researching, developing, and applying Distributed Acoustic Sensing.

The goal is to make it easier for students, researchers, engineers, and practitioners to discover high-quality DAS resources without having to search across scattered papers, datasets, software repositories, documentation, and websites.
